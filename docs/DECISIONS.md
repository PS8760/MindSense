Every deviation from `prompt.md` and every judgement call is recorded here (Rule 6).

| # | Date | Area | Decision | Rationale |
|---|------|------|----------|-----------|
| 1 | 2026-10-08 | Repo layout | The repository root **is** the `mindsense/` project root (no nested folder). | Standard for a git clone; paths in `config.yaml` stay relative to root. |
| 2 | 2026-10-08 | Environment | Python 3.11 venv at `.venv`, dependencies managed with `uv` but pinned in plain `requirements*.txt` files. | `uv` is only a fast installer; the pinned requirement files remain the source of truth so graders can `pip install -r`. |
| 3 | 2026-10-08 | Dependencies | Runtime vs training split exactly as Section 4: no torch/transformers in `requirements.txt`. | Keeps the deployed image light (Section 0.4). |
| 4 | 2026-10-08 | Quality tools | `pytest` and `ruff` live in `requirements-train.txt`, not in the runtime file. | They are needed by `make test`/`make lint` and CI but never at inference. |
| 5 | 2026-10-08 | App export | Placeholders for dataset availability are filled only after `scripts/download_data.py` runs; synthetic fallback rows are tagged `data_source="synthetic"`. | Rule 2 / Section 5.6. |
| 6 | 2026-10-08 | DASS scoring | Severity bands are applied to the **raw 14-item sum 0–42**; the "multiply by 2" rule is *not* used. | The ×2 step exists only to map DASS-21 onto DASS-42 (checked: 21-item moderate 7–10 ×2 = 14–20 = 42-item moderate). Applying it to DASS-42 produced a nonsensical 68 % "extremely severe" rate; correct scoring yields depression 22/10/18/16/34 % (N/M/Mo/S/ES). The skew reflects self-selection (people who choose to take an online depression test), not population prevalence. |
| 7 | 2026-10-08 | DASS validity | Screen drops respondents endorsing ≥2 fake VCL words, age outside 10–100, straight-liners (all 42 items identical), test time <60 s → 38 337 of 39 775 rows. | Section 5.5; ≥2 (not ≥1) fake words avoids over-pruning legitimate respondents — flagged here as a judgement call. |
| 8 | 2026-10-08 | Harmonization | The shared schema is the *union* of both populations; fields a population never collected stay NaN (students: no `support_available`; professionals: no sleep/finances/diet) rather than being imputed or encoded as fake categories. | No information exists to impute from; XGBoost/native-NN models handle NaN natively; models train per-population with a pooled native-NaN baseline for comparison. |
| 9 | 2026-10-08 | Feature mapping | `stress_pressure_score` = academic pressure (students) / `work_interfere` rank-scaled 0–5 (Never 0 → Often 5); `support_available` = mean(benefits, care_options) mapped Yes 1 / don't-know 0.5 / No 0. | Keeps one ordered 0–5 stress proxy and one 0–1 support proxy across surveys without inventing precision. |
| 10 | 2026-10-08 | Gender | Free-text gender collapsed to `male/female/other` (49 raw spellings in OSMI 2014; unknown → `other`). | Too-high cardinality for models; "other" preserves everyone without dropping rows. |
| 11 | 2026-10-08 | Splits | Modeling tables carry a `split` **column** (stratified 70/15/15, seed 42) instead of sidecar index files; drug_reviews and dreaddit keep their **official** source splits. | One source of truth inside the parquet; official splits are what comparable published results used. |
| 12 | 2026-10-08 | Leakage | The 7-class sentiment corpus contains 2 819 verbatim Dreaddit posts; both tables stay intact and `reports/tables/text_leakage_report.json` quantifies the overlap — Exp 7 must drop overlap rows from training before evaluating on Dreaddit. | Removing them at clean time would punish Exp 5 for an Exp 7 concern; the report makes the contamination impossible to miss. |
| 13 | 2026-10-08 | Repo hygiene | `data/processed/` is git-ignored alongside `data/raw/`; only aggregate reports (`reports/tables/*.csv`, quality/leakage JSON, generated dictionary) are committed. | Drugs.com is no-redistribution; several Kaggle sets have restrictive terms — never commit row-level data. |
| 14 | 2026-10-08 | Provenance | `make_synthetic` drops a `.mindsense_synthetic` marker in `data/raw/<key>/`; the inventory relabels such directories `synthetic` on every later run even though the files exist. | Fetchers only test *file presence*, so a stand-in from a previous run would otherwise be reported as real data (Rule 2). UCI DrugLib was unreachable → tier-C druglib is a labelled synthetic stand-in; delete `data/raw/druglib/` (incl. marker) and re-run `make data` once UCI is reachable. |
| 15 | 2026-10-08 | App ↔ model contract | The UI only imports `mindsense.inference` (`availability`, `predict_risk`, `predict_intervention`, `predict_severity`, `analyze_text`, `extract_entities`, `analyze_face`, `prognosis_info`, `reset_cache`). Every call returns `{"available": bool, "message"?...}` instead of raising when an artifact is missing; `ValueError` is raised only for invalid user input. Artifacts live in `models/` and are registered in `models/metadata.json` (`artifacts`, `model_versions`, `risk_tiers`, `prognosis.selected_items`, `feature_order`, `feature_means`); text models must be sklearn pipelines with steps `vectorizer`/`classifier`; the entity module must expose `extract_entities(text)`. | Keeps every page free of model-loading logic (Section 8) and lets the app render fully before `make train` exists; one place to swap artifact names per experiment. |
| 16 | 2026-10-08 | App structure | Crisis rules live in `mindsense/screening/crisis.py` (PHQ-9 item 9 > 0; suicidal-class prob ≥ 0.55; high-precision lexicon) and are shared by pages 1–4; the face module is off unless launched with `ENABLE_FACE=1`; face/PHQ/GAD/DASS instruments and their official item texts live in `mindsense/screening/`. | Single source of truth so the app, tests and pipelines can never disagree on a crisis trigger; face-off-by-default is a privacy + cold-start decision (Section 8, page 5). |
| 17 | 2026-10-08 | DASS in the UI | Page 3 shows the official 14-item DASS depression subscale with reference scoring when the trained compact screener (Exp 4) is absent; the official item texts come from the public-domain DASS-42 instrument (UNSW download page). No ×2 rescaling (row 6). | A working, honest screener before models exist — clearly labelled "instrument reference, not a model" — instead of a dead empty state. |
